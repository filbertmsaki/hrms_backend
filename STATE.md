## PROJECT ARCHITECTURE SUMMARY

- Backend: NestJS 11, TypeScript, REST API under `/api`, PostgreSQL, TypeORM 0.3, explicit migrations with `synchronize: false`. `AppModule` composes HR, auth, companies, users, roles, permissions, analytics, notifications, scheduled reporting, files, and other modules. The HR module composes employees, branches, departments, positions, dashboards, and workflows.
- Web: Next.js 16/React 19/TypeScript, predominantly App Router dashboard routes plus legacy Pages Router portal routes. `src/lib/admin-api.ts` is a major typed API client. Dashboard access, navigation, and section tabs live in `dashboard-permissions.ts`, `forbidden-routes.ts`, `dashboard-sections.ts`, `app-sidebar.tsx`, and `nav-main.tsx`. The UI uses Fluent, shadcn style components, Tailwind/CSS, and Recharts.
- Mobile: Expo Router/React Native app in `../hrms/android`, using the existing API, secure token storage, notifications, and tab navigation. Mobile KPI screens can be planned after the web/API contract is stable.
- Existing identity: `users` -> `company_users` (company membership) -> optional `employees`. Employees already reference company, branch, department, position, manager (`reports_to`), and additional department assignments. There is no dedicated team entity in the current HR model; manager reporting trees provide an existing team concept.
- Authentication: existing JWT/Passport access and refresh/session handling. `JwtAuthGuard` is global. `TenantGuard`, `PermissionsGuard`, permission decorators, and `HrAccessService` enforce company, branch, department, team, and self scopes. The frontend permission snapshot controls navigation but is not the security boundary.
- Deployment: separate Git repositories and CI workflows with UAT and production release pipelines. Backend CI includes lint, typecheck, unit and end to end jobs; web CI includes build and browser tests. Environment structure is represented by `.env.example` files. No secret values were read for this analysis.

       current_schema() AS default_schema,
       current_setting('server_version') AS postgres_version;
SELECT table_schema, table_name
FROM information_schema.tables
WHERE table_schema NOT IN ('pg_catalog', 'information_schema')
  AND table_type = 'BASE TABLE'
ORDER BY table_schema, table_name;

-- TypeORM migration ledger. No application rows are selected.
SELECT name, timestamp
FROM public.migrations
ORDER BY timestamp, name;

-- Relevant column shapes, including old KPI links in shared activity tables.
SELECT table_schema, table_name, column_name, data_type,
       udt_schema, udt_name, is_nullable,
       character_maximum_length, numeric_precision, numeric_scale,
       column_default
FROM information_schema.columns
WHERE table_schema NOT IN ('pg_catalog', 'information_schema')
  AND (table_name ~* 'kpi|performance|competency|scorecard'
       OR table_name IN ('daily_activity_entries', 'activity_categories')
       OR column_name ~* 'kpi|performance')
ORDER BY table_schema, table_name, ordinal_position;

-- Constraints, including foreign keys into or out of relevant tables.
SELECT ns.nspname AS table_schema, rel.relname AS table_name,
       con.conname AS constraint_name, con.contype AS constraint_type,
       ref.relname AS referenced_table,
       pg_get_constraintdef(con.oid, true) AS definition
FROM pg_constraint con
JOIN pg_class rel ON rel.oid = con.conrelid
JOIN pg_namespace ns ON ns.oid = rel.relnamespace
LEFT JOIN pg_class ref ON ref.oid = con.confrelid
WHERE ns.nspname NOT IN ('pg_catalog', 'information_schema')
  AND (rel.relname ~* 'kpi|performance|competency|scorecard|daily_activity_entries|activity_categories'

SELECT schemaname, tablename, indexname, indexdef
FROM pg_indexes
WHERE schemaname NOT IN ('pg_catalog', 'information_schema')
  AND (tablename ~* 'kpi|performance|competency|scorecard|daily_activity_entries|activity_categories'
       OR indexname ~* 'kpi|performance')
ORDER BY schemaname, tablename, indexname;
SELECT ns.nspname AS object_schema, rel.relname AS object_name,
       rel.relkind AS object_kind

JOIN pg_namespace ns ON ns.oid = rel.relnamespace
